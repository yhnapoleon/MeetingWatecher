# 下一批数据：独立泛化验证的采样与标注规则

2026-11-17。本协议已执行采集和预测前标注冻结：12例标注试验、40例自然正式会议、20例控制。正式60例测试与任务审计已完成，结果以[扩展集报告](generalization-v1-results.md)与[数据索引](../data/generalization-v1/README.md)为准。历史115例的任务识别P/R为94.7%/98.6%，见[旧任务指标报告](context-v5-task-metrics.md)；本轮不重跑旧例。

实际执行相对原规划的差异：中文采用VCSum的新会议（AliMeeting公开入口以大体积音频包为主），英文采用QMSum的ICSI Bed与Senedd教育委员会会议。52场自然原会议互不重复。正式自然输入共246,105个cl100k_base参考token；按实际长度分层为短于3K的7例、3K至8K的22例、8K及以上的11例，优先保留完整话题到语料记录结尾。正式参考为95个必需任务、9个可选任务，自然部分79个必需任务、控制16个。

实际标注为同服务模型独立整段预标注，再由执行助手复核证据与任务边界；不是双人独立人工盲标，亦非52份逐词独立人工复读。正式测试前冻结，不按测试输出改标签；预测后发现的标签争议保留主成绩并另做敏感性分析。本轮主标注范围是新增任务及容易误提取的非任务边界，不声称已完成下述所有事实、未决、跨会议更新指标的全量标注。

## 要回答的问题

现有95例核心场景和20例语义场景都已经参与过研究与调优。它们能检验回归表现；下一批要检验同一套冻结方案面对新会议、新领域、较长上下文时，是否仍能正确保留工作、决定与未决问题，并正确隔离不可靠解释。

新增数据分两部分报告：自然会议检验真实输入上的表现，控制样例检验机制边界。控制样例的人工比例不代表真实生产分布，不能把两者直接合并称为“线上准确率”。

## 首批规模与抽样

先选12例做标注流程试验，修订标注指南、解决分歧和估算成本；这12例属于开发材料，不进入最终未见集成绩。随后冻结60例独立测试：40例来自自然会议、20例为控制样例。数量是本轮的执行建议，实际来源不足时列出缺口，不用同一会议反复切片补足独立性。

自然会议40例至少来自30场不同会议，优先覆盖中文业务/教育等讨论24例、英文研究/公共事务讨论16例。具体领域须根据实际源材料标注，不能按语料名字预设内容。至少一半是常见、没有刻意注入错误的正常片段；没有后续工作的讨论也正常保留。选样不看当前模型输出。

控制样例20例按10对构造：每对只改变一个决定性条件，如“本人接受/未接受”“本场采用/历史引用”“仍开放/已回答”“立即安排/明确暂缓”“期限/工作时段”。必须包含能正确执行的相邻正例，不只收集困难反例。控制样例与其原型、改写、翻译放在同一个来源组。

长度分层采用输入token实测，不以字符数替代：约一半为2K以内的完整议题，约三成为2K—8K的连续多轮讨论，其余为8K以上的长上下文或整场会议。若一个任务的答复、承接或撤销在后文，不能截断后把它标为未决；保存可见输入的结束位置和切片理由。长输入若超出系统支持范围，要单列为范围外或机制失败，不悄悄缩短。

## 分组隔离与去重

1. 以原会议/系列为分组单位，先划分再切片。同会议的相邻片段、摘要问答、改写与翻译不能跨开发集和测试集。
2. 对当前115例建立来源索引：原始语料、meeting_id、series_id、片段范围及文本哈希。QMSum的AMI来源要与已有AMI材料交叉查重。
3. 新数据登记原文URL、版本、原始会议ID、转写版本、切片范围、许可、处理步骤和输入哈希。近似文本匹配仅用于提示重复，人工确认后记录依据。
4. 公共数据的“项目未见”不代表基础模型训练时未见。报告明确这是项目外推测试；若需要更强证据，另加入新近且授权的真实业务会议。

## 标注内容

每例在模型预测前固定四组标签：必需保留、允许省略、禁止误读、存在争议。每个命题都引用原始segment ID及原句，标明说话人、对象、范围和截至输入结尾的状态。

- 工作：动作与对象、负责人/账号是否明确、谁分派/谁承接、承诺或建议或条件、条件是否成立、工作时段与截止期限、创建还是更新、旧任务关联依据。
- 事实与决定：已发生/已确定/推测/引用的区别，主体、对象、数字、时间、否定和条件；英文相对时间要按原义核实。
- 未决：是否为本场提出或采用的问题；最终开放、已答、部分回答、撤销或暂缓；答案只解决了哪一部分；承接调查不等于问题已解决。
- 操作：允许/禁止创建或更新的任务，事项收录期望，权限和幂等约束。无真实账号映射的语料仅评价语义提取及正确拦截，不要求伪造平台账号。

自然语料原有摘要只能辅助找证据，不直接充当金标。明确哪些含义必须出现在特定栏目，哪些可跨栏目等价表达；时间短语保留在描述但结构化due_text缺失等情况单列字段指标，避免评测时临时改口径。

先用12例统一指南；正式60例由两名独立标注者分别完成关键命题，预测前仲裁分歧。如果只有助手标注与自我复核，明确标为“助手审计标签”，不能写成独立人工盲评。不确定的源句不强行制造唯一答案，保留可接受解释集合或单列敏感性分析。

## 冻结与评测

冻结输入、标签、代码、提示词、模型标识/返回版本、推理预算、重试策略及评分脚本，写入哈希。标签不进入生成请求。一次正常入口执行，保留所有原始响应、技术恢复和用量；不能重新抽样选最好结果。

主要报告按自然会议/控制样例、语言、领域、长度分层列出任务Precision、Recall和F1，以任务为单位微平均。分别统计动作/对象/范围识别和负责人、承诺/条件、时间均正确的完整任务匹配。预测前明确同对象交付链的拆并粒度、必需/可选项，以及items与真实工作确认卡按record_id去重的规则；同时报告items-only。错误匹配计FP及对应FN，partial场景不整例删除，其正确保留任务可命中、遗漏任务仍计FN。

纯隐式需求、尚未采纳的建议、完成/进度汇报和旧任务更新单独建立参考，不混入新任务分母；错误需求卡和错误追问不能被隐藏。对旧任务完成、重开、改期/清期，核对实际写入与禁止写入，区分提取正确和操作落地。无依据自动执行数、未决命题保留与误增、字段完整性、稳定收录、技术完成率、延迟和用量作为分项指标。整例全部语义正确率只作辅助诊断，事实区与任务无关的措辞错误不直接扣任务P/R。

自然会议多个切片的统计相关性按原会议分组处理；区间估计以会议为重采样单位，样本很少的分层直接给出分子/分母并注明不稳定。控制对按整对正确率报告，不能将同一原型的十种改写当作十场独立会议。

115例基线完成后，可以进入新数据采样标注。影响任务输出或实际更新的协议、状态、写入故障需定向验证；只阻塞纪要的partial不作为任务评测前置门槛。新集失败先归类，任何后续调优都另立版本；测试数据参与调优后改称回归集，新的泛化结论需要另一批未参与调优的数据。
