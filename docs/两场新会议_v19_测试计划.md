# 两场新会议：v19 测试与人工复核计划

目标是检查当前系统在另外两个参会小组上的完整会议表现。用户已认可 IB4005 的语义复核标准，本轮沿用“有原文支持的合理表达可算正确”，并把可接受答案提前写入参考。

选取 IS1000a（启动会，约25分钟，389段）和 TS3003b（功能设计会，约37分钟，404段）。两场都是 AMI 遥控器设计场景，来自不同小组；这能扩展会议与说话人样本，不能代表跨领域泛化。选样在推理前完成：分别取 IS、TS 组按名称排列首个至少有两项行动、两项决策、短于40分钟且未做过本地实验的会议。检索仅发现原始 QMSum 文件目录中的名称，未发现既往调优、模型输出或文档案例。

1. **先读原文、再冻结参考。** 主助手已完整阅读两场原文，保留 AMI 原标注，另存有证据段、可接受表达、不可接受扩写及调整理由的重注参考。IS1000a 为3项任务、8项决策；TS3003b 为4项任务、12项决策。参考不进入模型输入。
2. **保持配置，完整运行。** context-v5 v19、决策核验 v2、同模型和推理参数，两场分别使用空历史、空 SQLite 和全新响应目录。输入覆盖全部原词语，两场独立运行。
3. **限制恢复条件。** 使用现有自动恢复；技术失败时，每场最多追加一次现有 Service 恢复批次，保留首次结果。语义得分不理想不触发重跑，也不改提示。
4. **逐条人工复核。** 主助手亲自检查所有任务候选、所有决策主张及不能直接建任务的卡片。核对前后文、负责人、条件、时间、采纳与最终状态，说明每项匹配依据；遗漏项反查中间阶段定位。合理合并不拆成多个预测 TP，参考外有据内容也可正确。
5. **分别报告语义与运行质量。** 汇总任务及决策的精确率、参考召回率，并说明原 AMI 参考覆盖情况、栏目重叠、字段问题、恢复调用。若需运行后重注，另存修改及指标影响，不覆盖冻结参考。
6. **交付可复查证据。** 留存输入、原／重注参考、规则、原始响应、逐条判定、漏项归因、指标、配置与源码快照。验证数据库重开、HTTP 禁用下重复提交、输入参考哈希和源码一致。

推理开始前的主要重注：IS1000a 将“利润目标＋国际市场”拆开，把最终按钮清单改为“基础功能方向、具体按钮未定”；TS3003b 补入主持人归档纪要、营销人员继续调查老年市场两项承诺，分开声音定位与重复的老年定位，补常规材料决定。原文中条件性选择可接受，但不会把尚未承接的建议改成正式任务。
