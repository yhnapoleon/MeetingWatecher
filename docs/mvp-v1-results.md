## 实现与边界

| 模块 | 输入、处理与结果 |
| --- | --- |
| inputs.py | 统一公开片段和模拟会议，保留原标签、人员引用、账号映射与原件版本；缺时间不补猜。 |
| extract.py 与提示词 | 输出事实、未决问题、行动项、决策和状态提议；写入前验证字段、引用和授权历史目标。请求、原始响应、耗时与 token 单独落盘。 |
| store.py | SQLite 保存来源、抽取、写入意图、绑定、任务事件、决策与审计记录；本地模拟器提供 create/get/update。 |
| service.py | 在模型供数前限制租户、项目、时间和受众；创建及更新经持久化意图执行；任务状态和决策查询保留历史。 |
| CLI 与回放脚本 | 提供导入、回顾、决策、纪要和恢复入口；expected/labels 仅在验收与评分侧使用。 |

原始会议内容、旧版抽取与账号映射分别保存。公开人员代号可以用于判断负责人，但没有明确账号映射时写入停留在候选。相同来源版本直接复用，来源变化时存为 revision_pending，保留新抽取供核对；当前未自动决定如何修改原任务。

来源权限收缩立即影响历史查询，权限扩大也不会直接发布原受众下生成的旧纪要，以免旧纪要带出当时私有的历史内容。任务读取权与来源引用权分别检查。来源当前权限通过新导入版本表达，任务权限通过模拟器事件表达。

模拟器为本地离线测试使用永久 token，能够按原意图找回丢失回执。真实平台 token 的时效、调用身份与失败查询须在接入飞书时按平台契约实现。当前 CLI 的身份参数由受信任操作员提供，尚不承担网络服务的登录认证。

## 验证与审查

22 个自动测试通过，覆盖身份保留、证据拒绝、同段多任务、重复导入、丢回执重启、会签不整体完成、同名歧义、人员到账号映射、当前权限、历史截止点和来源修订。原数据校验仍通过：20 场会议、30 个片段、137 段发言、35 条事件初标及 6 个 workflow 检查。

独立代码审查发现恢复沿用旧权限、历史名册泄露、账号引用比较及延迟恢复回写历史四个问题。四项均增加可复现测试后修复：待发送操作重验权限；已成功但丢回执的操作只需读回；继承名册使用当前来源权限与共享受众交集；状态获知记录使用实际恢复时间。另验证未来生效事件不会提前进入查询，非法时间在持久化前拒绝，模型选出的 GUID 也不能绕过同名同负责人任务歧义。
