# MeetingWatcher 会议助手 · 提交说明

本项目围绕“谁答应了什么、什么时候交、上次的事情进展如何”建立数据标注、评测和应用。完整前端包括项目工作台、会议现场、动态纪要、行动事项、文字助手与归档；模型随新增发言生成内容，用户核对后确认任务，下一场继续更新同一对象。

## 阅读顺序

1. `04_技术报告/会议助手_项目复盘.pdf`：主报告，说明功能、架构、阶段演进与结果。
2. `05_演示视频/会议助手_双场完整演示.mp4`：15:13，第二场从 05:32 开始；同目录有观看时间表。
3. `04_技术报告/会议助手_任务与决策提取调优.pdf`：具体错误、改动、对照结果及保留的负结果。
4. `03_评测日志与结果/`：查看原文、标注、逐条判分、指标和当前应用核查记录。
5. `04_技术报告/会议助手_配置与运行说明.pdf`：安装与复现；同目录 Markdown 可编辑。

## 一条命令检查提交材料

需要 Python 3.11+。在本文件所在目录执行：

```powershell
python 复现.py check
```

入口核对文件清单的 SHA-256，把各类别自动映射成 `_运行工作区/` 中的常规项目结构，再复算两场新参会组的保存判分、运行 56 项核心定向检查并预检整会推理入口。全过程不调用模型。`python 复现.py prepare` 只准备目录；`--workdir <新目录>` 可指定独立核查位置。

运行完整应用时进入 `_运行工作区`，按配置说明创建虚拟环境、安装 Copilot 锁定依赖，在 `.env` 填入自己的模型凭据，启动 Python 服务和 Vite，再打开 `http://127.0.0.1:4173/?showcase=1`。安装依赖后可用虚拟环境 Python 执行根目录 `复现.py check --copilot`，增加 33 项 Copilot 离线测试。

输入为 AMI 原声及实际 STT 词轴回放，纪要、候选任务和文字交互在运行中调用模型生成。任务写入和成员邀请使用本地实现；在线 ASR 与真实飞书写入待联调。初次安装依赖需要网络，重新推理可能得到不同措辞。
