# 任务与交付标准

字节方提出的业务链路是会议生成纪要和行动项、写入飞书任务、下次会议回顾未完成项、跨会议积累团队决策。指定的首项工作是评测脚本和标注，重点覆盖多模态对齐、行动项抽取、状态闭环、跨会议关联和权限隔离。下列样本规模、状态规则和验收方法是 v0.1 建议，供带教讨论。

## 第一批交什么

首轮离线开发采用 24–36 个可独立判分的片段。当前批次已取得 20 场会议的 30 个片段并完成 35 条事件初标，其中 18 个英文片段附音视频。另以 3 个查询时点、2 个身份检查任务完成、重开及读权限撤回。人工复核、完整会议漏项和模型基线分别记录。[数据、范围与复核入口](../data/mvp-v1/README.md)

| 交付物 | 接手人如何验收 |
| --- | --- |
| 转写样本与来源清单 | 首批取公开多人会议原有转写和人工标注，登记版本、会议号、时间段、说话人及使用范围。按项目示例格式呈现，核对源发言顺序和可用字段。现有模拟快照用于会前状态和权限验收。 |
| 标注与口径 | 每项任务、决策、变更都能回到证据段；未知负责人和模糊日期可表达。每条连续会议样例另附会前任务、查看身份和时间点。先复核约十个有争议的候选，记录分歧和最终规则，再扩量。 |
| 可离线复跑的评分器 | 同一份输入和预测重复运行得相同分数。报告含样本数、指标分母、错例 ID 和原因。用漏项、多建、错人、错日期、串会、越权、缺预测各一条验证评分逻辑。 |
| 基线报告 | 同一批会议跑一次最小抽取基线，保留配置、模型版本、输入和预测。按公开转写、真实妙记、模拟链路分别报告结果与错例。小样本阶段先建立基线，再与带教议定质量目标。 |

## 怎么判定系统完成了任务

| 用例 | 可检查的预期结果 | 统计口径 |
| --- | --- | --- |
| 回放原话，找到承诺 | 提问与认领分属两人时，能定位两段证据和实际承诺人。若引用共享画面，还能回到相应帧或页。 | 按标注段计算证据 P/R；有人工校时音频的子集另报起止绝对误差、说话人匹配数/可核验段数。无媒体的样本跳过媒体指标。 |
| 从会议生成纪要和任务 | 纪要保留已决范围及未决问题；一个承诺生成一条任务，建议、否定或引用旧话不会触发新建。 | 行动项按一对一匹配算微平均 P/R/F1；在匹配项上分别统计负责人、期限。纪要逐条报已覆盖关键事实/应覆盖事实、无证据断言/输出断言。 |
| 写入后再开会 | 同一承诺重复消费只得到一个任务 GUID。会前完成的任务从清单移除，会上宣布完成的任务仍应出现在此前的会前清单。 | 比较操作类型、目标 GUID 和实际读回状态；单列重复创建数、状态转换正确数/应转换数及会前集合 P/R。 |
| 查团队过去的决定 | 用户能回答“当时决定什么、现在是否还有效、哪场会改了它”；两个项目都谈灰度时能区分对象。 | 用有方向的关系三元组（新决定、替代、旧决定）算 P/R；历史时点答案与其可见引用逐条核对。 |
| 不同人看同一议题 | 研发主持人能回顾授权事项；外协可看共享任务，私有任务的标题、数量线索、引用及搜索摘要均不应暴露。 | 给同一查询切换身份。正向检查应见集合；分别记录越权候选进入模型、输出泄露和未授权写入次数。固定权限回归样例要求三者均为零。 |

## 里程碑

新增的边界用例包括创建成功但丢回执后隔天重放、换调用身份重放、会签中单人汇报、任务重开、关注人只读和撤权后再问。跨会议证据检索分别报选对会议数、至少命中一段证据的题数及证据覆盖率。一个很长的窗口即使命中几句话也可能带入大量无关材料，同时报窗口内证据占比。[平台契约](platform-study.md) · [实测口径](corpus-study.md)

1. **标注口径走读（本稿）**。用随附两场模拟会逐项讨论明确指派、口头完成、决策替代和查看范围。当前可运行项是会前任务 ID 清单对照。
2. **离线首版**。使用带标注的公开会议与示例格式完成导入、抽取和计分，另用本地任务表回放跨会状态。报告分列公开语料和模拟流程的错例、耗时与模型用量。
3. **飞书集成验收**。在有相应权限的测试空间读一份妙记、创建一个测试任务、按同一 token 重放、用 GUID 更新并读回、以两种身份检查结果。记录实际导出格式、返回的 ID、权限差异和失败响应，作为真实写入链路的证据。

**需要带教定的三件事。** 生产入口是逐字稿、智能纪要还是两者都有？明确指派但对方未答复时是否建任务，负责人自报完成时是否允许自动关闭？权限以哪种身份取数、以谁能读取任务或决策为发布范围？前两项改变标注答案，最后一项决定集成样例的预期可见集合。
