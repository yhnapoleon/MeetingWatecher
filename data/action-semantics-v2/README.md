# 行动项语义评测 v2

三个数据视图分别报告。`regression` 的 21 个输入与旧开发集相同；`context` 是 C02+C03 的连续原文，标全范围内三项分工；`blind` 用于未参与调优的新会议，manifest 明确标识是否已准备好。

标签保持原事件 ID 和任务口径，补充 `required_content`、字段原话、复核依据及不确定性。C03.2、C09.1 的短回应仍按原初标计算，另记承接歧义；C09 的参考内容依赖问答及后续使用问题，笼统“看说明书”需要逐项评价内容是否充分，不能单凭命中引用给满分。

时间语义修订：C19“会后”、C20“后面”仅表示后续安排，v2 的截止时间字段留空，原表述保存在 `time_text`；旧标签和旧评分保持不变。C02/C07 的工作时段也不作截止时间。修订在新流程生成预测之前冻结。

评分依据独立复核文件。先导出原话、参考事件和完整预测，再逐条填写内容是否有依据、是否完整、负责人、承接、时间和操作是否正确，以及理由。复核使用 `agent_reviewed` 或 `human_reviewed` 标记，不把模型核验器自己的判断直接当作评测真值。

`score_action_semantics.py` 不含语义模型或关键词规则，只计算已复核的判断；它验证输入、标签和预测哈希及逐例覆盖。没有复核时拒绝给出正式语义分数。任务内容正确率与完全正确任务召回分别报告；调用失败仍在召回分母中，歧义参考单列而不删除。
